How to set up the local models

On an Apple Silicon Mac with Python 3.11 and uv installed, open a terminal in the BreedFrame repository and run:

sh scripts/setup.sh
sh scripts/start.sh

First-time setup needs internet access and several GB of disk space. It downloads both models. Keep the startup terminal running while using Scout, then choose Check again.

Already set up? Run sh scripts/start.sh. If another Ollama server is using port 11434, stop it from its own terminal before retrying setup. The repository’s docs/setup.md has troubleshooting steps.

How this works

Scout coordinates the investigation. Separate tools check image quality, analyze pixels, and assemble the assessment. All of this runs on this Mac.

S

Scout · chooses the next stepA language model reads recorded measurements and rankings to choose an action. Scout does not see the photo itself.

Q

Image checks · measure qualityPixel calculations measure size, brightness, and detail. These checks don’t identify a dog or its breed.

V

Vision model · compares breedsA Vision Transformer reads the photo or your selected region and ranks visual matches across 120 breed classes.

R

Assessment · presents the evidenceBreedFrame assembles recorded rankings and notes. Model scores describe visual matches; they aren’t calibrated probabilities of breed identity.
